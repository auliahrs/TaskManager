# 📋 Task Manager App

A full-stack To-Do application built to learn REST APIs.

## Tech Stack
- **Frontend:** AngularJS
- **Backend:** C# (ASP.NET Core Web API)
- **Database:** SQLite

## Features
- ✅ Create tasks
- ✅ View all tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Edit task titles
- ✅ Delete tasks

## How to Run

### Backend
```bash
cd backend/TaskManagerAPI
dotnet run
```

### Frontend
Open `frontend/index.html` with Live Server in VS Code.
